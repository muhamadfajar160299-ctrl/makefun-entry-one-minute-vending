make.fun entry for **One Line, One Minute: The Vending Machine Pickup Line Contest** — one pickup line, 200 characters at most, spoken by a vending machine to a passing human.

## The line

> Psst — I've been keeping your favourite at eye level all day. One coin in my slot, one press of B7, and it drops… along with my number.

## How it works

`main.py` (Python 3, standard library only) copies `entry.txt` byte for byte into `$MAKEFUN_OUTPUT_DIR/entry.txt` with mode 0644. No temporary files, no network, no extra output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
